# Storyteller

Geschichten zum Lesen und Hören, auf Deutsch und Englisch. Läuft direkt im Browser:
**https://leoz111.github.io/Storyteller/**

Aktuell: **Neun Glocken / Nine Bells**, eine Murim-Geschichte.
Er versteckte sich in einer Glocke, während seine Sekte starb. Einundvierzig Jahre später erwacht er neunzig Tage vor jener Nacht.

- Lesemodus mit Dunkel/Schwarz/Sepia/Hell und einstellbarer Schriftgröße
- Hörbuch mit eigener Stimme pro Figur (Gerätestimmen kostenlos, optional OpenAI-Stimmen)
- Fortschritt wird pro Sprache gemerkt
